## About

I am a full stack engineer focused on building production web platforms for education and commerce in Somaliland. My work spans the whole product lifecycle — from data modelling and API design to responsive, app-style interfaces deployed on Vercel.

- **Software Engineering** — TypeScript-first codebases, typed APIs, clean component architecture, and phase-by-phase delivery with review gates.
- **AI / ML** — LLM-assisted exam marking and feedback pipelines that turn student answers into structured, actionable scoring.
- **Full Stack** — Next.js, React, Node.js, Flask, PostgreSQL / Supabase, and serverless deployment.
- **Product Engineering** — I build for real users: schools, students, volunteers and local merchants, with mobile-first UX and localisation in Somali.

**Open To:** Full stack and AI engineering roles · EdTech collaborations · Freelance product builds · Open source contributions
